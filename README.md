# openConvert

موقع عربي RTL لتحويل ملفات الصور والصوت والفيديو والمستندات، وفحص وتنزيل الروابط التي يستطيع yt-dlp استخراج الوسائط منها. قائمة الصيغ التي تظهر في الموقع تأتي من قدرات المحركات المتاحة على الخادم.

## التشغيل على Windows

المتطلبات: Python 3.11 أو أحدث، وFFmpeg/FFprobe. LibreOffice مطلوب لتحويل المستندات. yt-dlp وPillow وخادم API يثبتها ملف الاعتمادات.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
python server.py
```

افتح http://127.0.0.1:8000. يربط الخادم نفسه بواجهة loopback فقط. لإضافة المحركات على Windows عند عدم توفرها:

```powershell
winget install --id Gyan.FFmpeg.Shared --source winget
winget install --id TheDocumentFoundation.LibreOffice --source winget
```

بعد التثبيت، أعد تشغيل التطبيق كي يكتشفها.

## ما يعمل حاليًا

- الصور: صيغ الإدخال والإخراج المعلنة تُكتشف من محركات Pillow المثبتة. تشمل صيغًا شائعة وأخرى مثل AVIF وJPEG 2000 متى دعمها المحرك. GIF المتحرك يخرج كصورة ثابتة للإطار الأول.
- الصوت والفيديو: يستخدم FFmpeg لفك وترميز الملفات التي تقبلها النسخة المثبتة. قائمة الإخراج تتغير حسب الترميزات المتاحة. تحويل الفيديو يعيد ترميز الصورة والصوت؛ استخراج الصوت متاح عند وجود مسار صوت.
- المستندات والنصوص والعروض وجداول البيانات: LibreOffice يحول ضمن عائلات الملفات المناسبة. جودة التخطيط تختلف حسب المستند الأصلي.
- تنزيل الوسائط: yt-dlp يتضمن مستخرجات لآلاف المواقع، لكن عمل الرابط يتغير مع تغييرات المنصات، الجغرافيا، تسجيل الدخول، وقيود النشر. يفحص الموقع الرابط أولًا ويعرض الجودات التي استخرجها فعلًا. لا يدعم هذا الإصدار DRM أو المحتوى الخاص الذي يحتاج جلسة دخول.
- حد الرفع 150 ميغابايت، وحد تنزيل الناتج 512 ميغابايت، والمدة القصوى ساعتان.
- الملفات المؤقتة تُحذف بعد إرسال النتيجة. لا يستخدم الموقع تخزينًا دائمًا.

## واجهات API

- `GET /api/health` حالة المحركات.
- `GET /api/capabilities` الصيغ والمحركات المتاحة حاليًا.
- `POST /api/convert` ملف `file` وصيغة `target` كحقول multipart.
- `POST /api/media/info` رابط JSON بصيغة `{ "url": "https://..." }`.
- `POST /api/media/download` حقول multipart: `url`, `mode`, `quality`, `output_format`.

## التحقق

شغّل التطبيق ثم نفّذ:

```powershell
.venv\Scripts\python.exe tests\integration_smoke.py
.venv\Scripts\python.exe tests\conversion_matrix.py
.venv\Scripts\python.exe tests\media_platform_smoke.py
```

الاختبار الأول ينشئ ملفات قصيرة محليًا، ويختبر التحويل وفشل المدخلات غير الصالحة. مصفوفة الصيغ تختبر كل صيغ الإخراج التي يعرضها المحرك المثبت. اختبار يوتيوب ينزّل عينة عامة قصيرة الجودة؛ يحتاج إلى اتصال إنترنت، وقد يتأثر بتغيرات المنصة.

## حدود النشر

الإعداد الحالي للتشغيل المحلي. قبل فتحه للإنترنت يحتاج إلى مصادقة، وحدود طلبات وحصص لكل مستخدم، عامل معالجة معزول، تنظيف دوري للملفات المؤقتة، وضوابط خروج شبكي أقوى ضد SSRF. محركات تحويل الملفات والتنزيل تستهلك مساحة تخزين ووقت CPU ونقل بيانات؛ الاستضافة العامة قد تفرض تكاليف.
